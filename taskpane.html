          Type {load} wherever the load number goes: you're asked for it, and the BOL number, each time. The subject is the load number, BOL and POD(s), like 3645493 // 7720418 POD(s).

          Accessorials

          For customers that get the POD only when there's an accessorial. It's listed under Accessorial Only in the Email menu (closed to start), and Create email needs an accessorial picked. Its subject names the accessorials, like 3645493 // 7720418 - Lumper.
          Each accessorial tagged in the list (or on its pages, in the preview) gets a file of its own: Lumper in one like 3645493 Lumper, and Other in one named for its type, like 3645493 Scale Ticket. Detention and Layover go with the PODs. Off: tagged files go after the PODs, in the same file.
          When an accessorial is picked, Create email opens two emails: the PODs, and a request like 3645493 // 7720418 - Lumper/Detention with the PODs and accessorial files attached and the details in it.

          PDF

          When the email's created, the POD opens in your browser with the print screen up (this needs Attach automatically).

          A PDF over 10 MB is split, in page order, into 3645493-1, 3645493-2 and so on, all attached to the same email. Stop files are kept whole.
