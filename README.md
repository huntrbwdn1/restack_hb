# Restack for Outlook

An Outlook add-in that lists every attachment in an email thread, lets you preview them, and combines the ones you pick into a single PDF to email or save. Restack was called Thread Attachments before 0.13; it's the same add-in (same ID), so team keys and published templates carry over.

**Status:** test build 0.26.

## Install

Open this repository's GitHub Pages site (the address shown under **Settings → Pages**). The team admin creates a team install file there once, installs it, adds the team templates in the admin console (in Restack: **Settings → Admin console**) and publishes them, then sends the install file to reps. Teams that already use Thread Attachments get the new install file from the admin console instead (**Team settings → Files → Install files**), which keeps the team key.

The site's wiki (`wiki.html`, with its pictures in the `wiki` folder) explains every feature, how to use it and how to install, for reps and team admins. Restack opens it from **Settings → Help**, the admin console from its **Help** link, and the install page links to it.

To try a new version before reps get it, put it in the repository's `beta` folder and use **Restack Beta** (the admin console's **Team settings → Files → Install files → restack-beta.xml**), which installs next to Restack and runs whatever is in that folder.

## What it does

- Lists each attachment once, oldest first, across all the selected emails in a thread, with a small picture of each file (page 1 of a PDF or fax, or the photo) and type icons for the rest.
- Pictures in an email's body: small ones in the sender's signature (logos, icons) are hidden under Show logos & icons, while a picture pasted into the message itself, like a screenshot of a receipt, stays in the list even when it's small. Restack reads each email's HTML to tell them apart (Outlook, new Outlook, Gmail and iPhone mark their signatures); a small picture it can't place is hidden, as before.
- Pick individual files, or Select all. Nothing is checked until you pick.
- Set the order files go into the PDF: checked files are numbered; drag one by its number or use its up/down arrows.
- The Accessorial tag on each checked file (and each page, in the preview) is a drop-down: Lumper or Other, the accessorials with paperwork of their own, and Not an accessorial to take a tag off. A file tagged either goes to the bottom of the order. With a template set to put accessorials in their own file, each one tagged gets a file of its own: "3645493 Lumper", and for Other its typed type, like "3645493 Driver Assist". Otherwise (and in Save PDF) the tagged files and pages go after the PODs, in the same file. Detention and Layover have no file of their own: the PODs are their paperwork. Tagging a file adds its accessorial on the Create email step (and takes it off again if the tag changes before anything's put in it), and Create email asks for it there if it's taken off. On a Multi-stop load, a tagged file goes with the PODs' last stop; its stop picker changes that.
- Previews PDFs (including fax-style and JPEG 2000 scans), photos and multi-page fax scans (TIFF) in the side panel. Move a scan's pages into the right order with the arrows on each page; the attachment itself isn't changed.
- Photos go into the PDF at most 2000 pixels on their long side: the whole photo, smaller, never cropped.
- Combines PDFs, photos and scans into one PDF, then emails it or saves it under a name you type.
- Every PDF stays under 10 MB: a bigger one is split into name-1, name-2… keeping page order, all attached to the same email (a Lumper or Other file too, like "3645493 Lumper-1"). Stop files are kept whole, with a note if one is over.
- Every email stays under the email size limit (a team setting on Team settings → Files, 35 MB to start, as mail servers count it: files travel in an email as text, about a third bigger). When a load's files would make an email bigger, Create email makes the scanned pages and photos smaller (redrawn at about 150 dpi, then 120 if need be; typed pages stay as they are), and if that still isn't enough, opens it as two emails or more, "(1 of 2)", "(2 of 2)", with as many files in each as fit. Emails under the limit and Save PDF don't change.
- Email templates: team templates, made by the team's admins in the admin console. Reps can add their own in Outlook (Settings → My templates) only once an admin allows it. Every email asks for the load number, names the PDF after it, fills in the recipients and message, and uses the subject "<load> POD(s)".
- Per-template options: say "No Lumper" when Lumper isn't picked; each stop in its own file or all stops in one; accessorials in their own file (each one tagged in its own, like "3645493 Lumper", and one for each stop when the stops have their own) instead of after the PODs.
- Accessorial Only (per template): for customers that get the POD only when there's an accessorial. These templates have their own Accessorial Only section in the Email menu, closed to start (even when Other templates is opened), and Create email needs an accessorial picked. They can still be pinned.
- Accessorials in a separate email (per template): when an accessorial is picked, Create email opens two emails. The POD email has the usual subject and the PODs. The request ("<load> - Lumper/Detention Request", with Other's typed type) has the PODs and the accessorial files (in one file with the PODs, unless the template puts accessorials in their own), the accessorials' details, and its own To, CC and message (a blank To uses the POD email's; a blank CC means no CC).
- Template questions: a pop-up asked when the template is picked, before the email step. Each answer goes to the next question, jumps ahead to a later one, continues to the email, or stops with a message. {company} fills in with the template's name.
- Rate confirmation check: an admin adds some of the team's rate confirmations in the admin console (Team settings → Files), as PDFs: the first 3 pages of each, up to 20 files. More can be added later, or one removed, without replacing the rest. Pages like any of them (digital, scanned or faxed, compared by words and by layout), pages that say Rate Confirmation or Load Confirmation, and pages with the same barcode number as a flagged page are flagged and must be left out (or cleared) before emailing or saving.
- Multi-stop: one PDF per stop, named load-1, load-2…. Each checked file gets a stop number, and a PDF holding several stops can be split by picking a stop for each page in the preview.
- Accessorials: when creating the email, Add an accessorial adds each one the load has (several can go on one load), each in its own box with a × to take it off: Lumper (shipper or receiver, total), Detention (shipper or receiver, IN, APPT and OUT times, hours requested), Layover (shipper or receiver, IN and OUT dates and times, APPT time) or Other (shipper or receiver, type, an explanation, and an optional total). They're listed in the message, Other under its type with the explanation as typed. On a Multi-stop load, the receiver choices name the stop, like "Receiver (Stop 2)".
- Times are 24-hour, like 14:30: pick one from a list every 15 minutes, or type one (830, 0830, 8:30a, 2:37 pm and 1430 all work; n is the time now). Dates have a calendar, or take a typed date in most forms (10/19, 10-19-2026, 2026-10-19, Oct 19, 19 October 2026) and show it as 10/19/26; a date without a year is this year. t or today is today, and n is today with the time now.
- When only one email comes through, a tip says so, and its info icon plays a short how-to for selecting every email in the thread (new Outlook, classic Outlook, or mail not shown as conversations).
- Keep adding (for mail not shown as conversations): with the panel pinned, each email clicked adds its files to the list. Restack asks first when one looks like a different load.
- Pick individual pages of a PDF in the preview, for example the POD but not the rate confirmation sent in the same file.
- Rotate pages and photos in the preview, a quarter turn per click, so sideways scans and photos go into the PDF upright. The attachment itself isn't changed.
- Settings: the gear at the bottom of the panel, there whatever email is selected (even one without attachments, or none). It has My templates (each person's own, for whoever may make them), Admin console (for team admins), Appearance (Light, Dark or Match Outlook), Text size (Small, Medium, Large), View (Large, Medium or Small pictures, List, Details, Tiles), switches for Tag accessorials by file name and Keep adding (each with a line saying what it does), and Help, which opens the wiki. Each person's choices are saved in their Outlook account.
- Templates are listed A to Z. Pin the ones you use most to the top of the Email menu and put them in your own order; the rest are under Other templates, and Accessorial Only templates in a section of their own. A new template starts with every box unticked.
- Several templates at once: on a new template (or a copy), in the admin console or My templates, Add Customer adds another template name and To. Save makes one template for each customer, all with the same CC, message, accessorials, questions, PDF name and file options, and each can be edited on its own afterwards. Names and addresses copied from two columns in Excel paste in one go (up to 50 at a time).
- Outlook keeps about 32 KB of each person's Restack settings, their own templates included. A change that won't fit isn't saved, and Restack says so. The admin console keeps its unpublished changes in the browser, with room to spare.
- Tag accessorials by file name: files with the admin's words in their name (lumper and receipt to start) start out tagged Lumper.
- Team admins: everyone on the admin list gets Settings → Admin console in Outlook. Add or remove admins on the admin console's Team settings tab, then publish. To publish what they change, an admin also needs upload access to this repository.
- Sent with restack (a team setting, off to start): every email Restack creates, the accessorial email too, ends with a small "sent with restack" line under the message, above the rep's own Outlook signature. It's a picture from this site (`sent-with-restack.png`) that Outlook attaches inside the email, so it shows without a "download pictures" prompt and looks the same in every mail app.
- Template form (in the admin console and My templates): in four groups, each under its heading: Email (name, To, CC, message), Accessorials (Accessorial Only, No Lumper, Accessorials in their own file, Accessorials in a separate email), PDF (its name, and stop files) and Questions. In the admin console, Save template stays in sight at the bottom of the window.
- Admin console (console.html, opened from Settings → Admin console in Outlook): the only place the team's templates and settings are made. Team settings is on four pages, one showing at a time: Tokens/Keys (Publishing, Attach automatically, Usage counts, This browser), Files (Install files, Rate confirmation check, Accessorial file names, Email size limit), Toggles (Reps' own templates, Sent with restack) and Admins (Team admins). The list on the left has the pages' names and shows the one picked; on a narrow window it's a Go to drop-down. The console opens on the page you were on last. Two admins can work at once: unpublished changes stay in the browser they were made in, and Publish to team adds them to whatever's published (read from GitHub itself), asking which to keep only when both changed the same template or setting; opening the console brings in what others published since. The Team admins card says what someone you add needs of their own: upload access to the repository (and their own GitHub token) and the usage admin key. Help, by the tabs, opens the wiki. Full size in a browser, publishing straight to GitHub with an optional token, and a Usage tab. With nothing published yet, it starts a new team, with whoever opened it as its admin. Before 0.22 admins could change team templates in Outlook too: publish any changes left there before updating, since Outlook can't publish them any more.
- Usage counts: with the admin's Restack Usage Azure function (its own Function App, kept outside this site), each panel counts the PDFs saved, emails created, files, pages and rate cons caught, shown on the console's Usage tab by day, rep and template. An email for the same load and template counts once a day, however many times it's created. Time saved uses minutes per email created (3 to start) and per PDF saved (1 to start), set on the Usage tab.
- Optional automatic attaching: with the team admin's PDF Emails Azure function (its own Function App, kept outside this site), Create email opens with the PDF already attached.

## Changing the wording

Most labels reps see on the panel (Select all, Accessorial, Email, Create email, Detention, Include in PDF and so on) are in one list at the top of `taskpane.js`, called `WORDS`. Change the text between the double quotes, keep anything in {curly brackets}, and upload the file. An apostrophe is fine; a double quote inside the text isn't. Each label changes everywhere it's used, including the email's accessorial lines, within a few minutes (or close and reopen Outlook). Messages and warnings, and the template screens, aren't in the list.

## Privacy

Everything runs inside Outlook's side panel. Attachments are read and combined on your computer. Only when the team admin turns on automatic attaching are PDFs made with Email uploaded, to the admin's PDF Emails Azure function, for Outlook to download into the new email. Download links stop working after an hour, and expired files are deleted. When the team admin turns on usage counts, each panel sends counts to the admin's Restack Usage Azure function: the rep's email address, when, how many files, pages and PDFs, the template's name and which accessorials. Never files, file names, load numbers or customer addresses. `team.json` holds the team templates and settings encrypted with the team key, which only the team install file contains. Personal templates are saved in each person's Outlook account.
