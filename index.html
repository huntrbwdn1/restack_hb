Restack for Outlook

Test build 0.16

See every attachment in an email thread in one list, preview them, and combine the ones you pick into a single PDF to email or save.

Updating

  1. Upload the new files to this repository, next to the ones already here. Keep the team.json that's already here.
  2. That's all: everyone gets the new version the next time they open the panel. If it still shows the old one, close and reopen Outlook.

Restack used to be called Thread Attachments. It's the same add-in, so your team key and published templates carry over. The ribbon button keeps the old name and icon until the add-in is reinstalled, which is optional. To do it, first publish any template changes you haven't published yet: removing the add-in may also clear what's saved in it, like unpublished changes or a rep's own templates. Then get the install file from the add-in (Settings → Team → Share install file, which downloads restack-team.xml), remove the old add-in and install this one, as below.

Don't use the Create team install file button below to update. It makes a new team key, which can't open the templates you've already published.

Try a new version first: Restack Beta

Restack Beta is a second copy of the add-in, just for you, that runs whatever is in this repository's beta folder. It sits next to Restack in Outlook, so you can try a new version on real emails before your reps get it.

  1. Once: upload the beta folder (a full copy of Restack) to this repository, so it sits next to these files.
  2. Once: in Restack, choose Settings → Team → Share beta install file, and install the restack-beta.xml it downloads the same way as Restack's (aka.ms/olksideload → My add-ins → Add a custom add-in → Add from File). It shows up as Restack Beta, with a black β on its icon.
  3. Each new version: upload its files into the beta folder first and try them in Restack Beta. When it's ready, upload the same files to the main folder.

Restack Beta uses your published templates and team settings. Its own choices (Appearance, Text size, View, pinned templates) and any template changes you haven't published are kept apart from Restack's. Keep restack-beta.xml to yourself: it carries your team key.

Admin console

For the team admin: Settings → Team → Open admin console opens a full-size page in your browser. Templates has the list and the editor side by side, with search and Make a copy. Team settings has everything under Settings → Team, and lets you set the rate con sample from a PDF on your computer. Usage shows what your team makes with Restack.

The console starts from what's published, so publish changes you've made in Outlook first. Publish to team downloads team.json for you to upload, as in Outlook; with a GitHub token under Team settings → Publishing, it goes straight to this repository instead. The console keeps your team key in that browser so a bookmark works next time; Team settings → This browser removes it.

Usage counts

With your own Restack Usage Azure function (a small Function App of its own; its folder has the setup steps), each rep's panel counts what it makes: emails created, PDFs saved, files combined, pages and rate cons caught. The admin console's Usage tab shows them by day, by rep and by template, for any dates, with a CSV download. Only counts are sent, never files, file names, load numbers or customer addresses.

Set up your team

Do this once. You'll manage the team's email templates, and only people you send the install file to can use the add-in.

  2. In Outlook, remove any older copy of the add-in: open aka.ms/olksideload, choose My add-ins, and under Custom Addins choose … → Remove.
  3. In the same window, choose Add a custom add-in → Add from File, pick restack-team.xml, and choose Install.
  4. Open Restack in Outlook, choose Email ▾ → Create a template…, add your team templates, and click Publish to team. Upload the team.json it downloads to this repository (Add file → Upload files → Commit changes).
  5. Send the same restack-team.xml to your reps.

Keep that file. Clicking the button again makes a new team key, which can't open templates you've already published. You can download it again any time from the add-in: Settings → Team → Share install file. Anyone who has the file can use the add-in and see the team templates, so share it only with your team.

Install (reps)

  1. Save the restack-team.xml file you were sent.
  2. Open aka.ms/olksideload. Outlook opens the Add-ins for Outlook window after a few seconds.
  3. Choose My add-ins. If Thread Attachments is under Custom Addins, choose … → Remove on it first. Then choose Add a custom add-in → Add from File, pick the file, and choose Install.
  4. New Outlook and Outlook on the web show the button right away. Classic Outlook can take up to a day.

No Add a custom add-in option? Your organization doesn't allow installing custom add-ins. An admin can deploy the same file from the Microsoft 365 admin center (Settings → Integrated apps).

Use

  1. Select every email in the thread. In new Outlook or Outlook on the web, click the arrow next to the conversation to open it, then tick the checkbox at its top. In classic Outlook, click the arrow next to the conversation, click the first email under it, then hold Shift and click the last one. If only one email comes through, the panel says so; hover over or click its info icon to see how. If your mail isn't shown as conversations, pin the panel and turn on Keep adding (in that tip, or in Settings): each email you click adds its files to the list, and Restack asks first if one looks like a different load.
  2. Click Restack on the ribbon. Every attachment shows up once, oldest first, even if it was sent back and forth, with a small picture of it so you can tell a POD scan from a photo of the truck.
  3. Check the files you want, or Select all. Nothing is checked until you pick. Click a picture or the eye icon to preview a file, untick any pages you don't want, turn any that are sideways with the rotate button on the page (a quarter turn per click), and put a scan's pages in the right order with the arrows next to each page. Checked files are numbered in the order they go into the PDF: drag a file by its number, or use its arrows, to change it. Tick Receipt on a lumper receipt (or on its page in the preview) and it always goes after the PODs, or into its own file if the template says so.
  4. For a load with more than one stop, tick Multi-stop. Each file you check gets a stop number (change it if it's wrong, or to put two photos in one stop). If one PDF holds several stops, open its preview and pick a stop for each page. You get one PDF per stop, named 3645493-1, 3645493-2 and so on. A stop's POD that comes in later can go out on its own as -2.
  5. Choose Email ▾ and pick a template (or Blank email). If the template has questions, answer them first; an answer can stop you with a message about what's missing. Type the load number, and tick Detention, Layover, Lumper or Other to add those details to the message. On a Multi-stop load, pick which stop each one was at. Create email names the PDF after the load and opens a new email with the recipients and message filled in. The subject is always the load number and POD(s), like 3645493 POD(s). If your team admin has set up automatic attaching, the PDF is already attached; otherwise click Attach PDF on the new email's ribbon. To keep a copy instead, choose Save PDF… and type a name.

Every PDF stays under 10 MB. A bigger one is split, in page order, into 3645493-1, 3645493-2 and so on, all attached to the same email (Save PDF does the same). Stop files and receipt files are kept whole; the panel says so if one of them is over 10 MB.

PDFs, photos and fax scans (TIFF) go into the combined PDF. Word and Excel files are listed but can't be combined yet. Only the team admin makes templates to start with. To let reps add their own too, the admin turns on Reps can make templates under Settings → Team and publishes. Each template can say No Lumper when there isn't one, put every stop in one file or each in its own, and send receipts as their own file. A template set to send Accessorials in a separate email opens two emails whenever Detention, Layover, Lumper or Other is ticked: the PODs as usual, and a request like 3645493 - Detention/Lumper Request with the PODs and receipts attached, sent to the template's accessorial address (or the POD email's To, if that's left blank), with its own CC if the template has one. Tag receipts with Receipt on the file, or on its pages in the preview; otherwise they go after the PODs in the same file. A template can also have a checklist that has to be ticked before the email opens, and questions asked in a pop-up when it's picked. Each answer goes on to the next question, jumps ahead to a later one, continues to the email, or stops with a message. The template's Customer name fills in {company} in them.

Rate confirmation check: the team admin previews one of your rate confirmations (up to its first 3 pages) and clicks Use as rate con sample (or chooses the PDF in the admin console), then publishes. Pages that look like it are flagged: digital copies, and scans or faxes of it, compared by their words and by their layout. So are pages that say Rate Confirmation or Load Confirmation, and pages with the same barcode number as a flagged page. Flagged pages have to be left out, or marked as not a rate con, before anyone can email or save. Phone photos of a rate con usually aren't recognized.

Settings: the gear at the bottom of the panel, across from Test report, is there whatever email is selected, even one without attachments. It has Manage templates (for whoever can make templates), Team (for the team admin: publishing, install files and the team's settings), Appearance (Light, Dark or Match Outlook), Text size (Small, Medium or Large), View (Large, Medium or Small pictures, List, Details or Tiles, like File Explorer), and two switches: Tag receipts by file name (files with words like lumper or receipt in their name start out tagged Receipt; the admin sets the words) and Keep adding. Each person's choices are saved in their Outlook account.

Templates are listed A to Z. Click the pin next to a template in Email ▾ to keep it at the top, and use the arrows next to your pinned ones to put them in the order you like. The rest are under Other templates. Pins are saved for each person.

Privacy

The add-in runs inside Outlook. Attachments are read and combined on your computer. If your team admin turns on automatic attaching, PDFs made with Email are uploaded to the admin's own Azure function so Outlook can download them into the new email; those links stop working after an hour and the files are then deleted. If your team admin turns on usage counts, your panel sends counts to the admin's own Azure function each time it saves a PDF or creates an email: your email address, when, how many files, pages and PDFs, the template's name and which accessorials. Never the files, file names, load numbers or customer addresses. Team templates and settings are stored on this site encrypted with your team's key, which only your install file contains. Personal templates are saved in each person's Outlook account.
