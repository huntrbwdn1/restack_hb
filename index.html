Thread Attachments for Outlook

Test build 0.3

See every attachment in an email thread in one list, preview them, and combine the ones you pick into a single PDF to save or print.

Install

  2. Open aka.ms/olksideload. Outlook opens and shows the Add-ins for Outlook window after a few seconds.
  3. Choose My add-ins. Under Custom Addins at the bottom, choose Add a custom add-in → Add from File, pick the file you just downloaded, and choose Install.
  4. New Outlook and Outlook on the web show the button right away. Classic Outlook can take up to a day to show it.

No Add a custom add-in option? Your organization doesn't allow installing custom add-ins. An admin can deploy the same file for you from the Microsoft 365 admin center (Settings → Integrated apps).

Use

  1. Select the emails. In new Outlook or Outlook on the web, click the conversation and every message in the thread is included. In classic Outlook, expand the conversation and Ctrl+click its messages.
  2. Click Thread Attachments on the ribbon. Every attachment shows up once, oldest first, even if it was sent back and forth.
  3. Check the files you want (or Select all). Click the eye icon to preview one.
  4. Choose Save PDF…, type a name for the file and click Save. Or choose Print… (pick Save as PDF or Microsoft Print to PDF to save a file), or Put in new email, then click Attach PDF in the new email.

PDFs, photos and fax scans (TIFF) go into the combined PDF. Word and Excel files are listed but can't be combined yet.

Only want some pages of a PDF, like the POD but not the rate confirmation sent in the same file? Open its preview and untick the pages you don't want. The list shows which pages you picked.

Privacy

The add-in runs entirely inside Outlook. Attachments are read and combined in the side panel on your computer, and nothing is sent anywhere. This website only hosts the add-in's code.
