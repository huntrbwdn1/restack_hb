Install (reps)

  1. Save the restack-team.xml file you were sent.
  2. Open aka.ms/olksideload. Outlook opens the Add-ins for Outlook window after a few seconds.
  3. Choose My add-ins. If Thread Attachments is under Custom Addins, choose … → Remove on it first. Then choose Add a custom add-in → Add from File, pick the file, and choose Install.
  4. New Outlook and Outlook on the web show the button right away. Classic Outlook can take up to a day.

No Add a custom add-in option? Your organization doesn't allow installing custom add-ins. An admin can deploy the same file from the Microsoft 365 admin center (Settings → Integrated apps).

Use

  1. Select every email in the thread, and click Restack on the ribbon.
  2. Check the files you want, in the order you want them.
  3. Choose Email ▾, pick your template, type the load number and any accessorials, and choose Create email. Or choose Save PDF….

The wiki has the details, and so does Settings → Help in Restack.

Set up your team

For the team admin. Do this once. You'll manage the team's email templates, and only people you send the install file to can use the add-in.

  2. In Outlook, remove any older copy of the add-in: open aka.ms/olksideload, choose My add-ins, and under Custom Addins choose … → Remove.
  3. In the same window, choose Add a custom add-in → Add from File, pick restack-team.xml, and choose Install.
  4. Open Restack in Outlook and choose Settings (the gear at the bottom) → Admin console. Add your team templates there and click Publish to team. Upload the team.json it downloads to this repository (Add file → Upload files → Commit changes).
  5. Send the same restack-team.xml to your reps.

Keep that file. Clicking the button again makes a new team key, which can't open templates you've already published. You can download it again any time from the admin console: Team settings → Install files. Anyone who has the file can use the add-in and see the team templates, so share it only with your team.

Updating

  1. Upload the new files to this repository, next to the ones already here. Keep the team.json that's already here.
  2. That's all: everyone gets the new version the next time they open the panel. If it still shows the old one, close and reopen Outlook.

Restack used to be called Thread Attachments. It's the same add-in, so your team key and published templates carry over. The ribbon button keeps the old name and icon until the add-in is reinstalled, which is optional. To do it, first publish any template changes you haven't published yet: removing the add-in may also clear what's saved in it, like unpublished changes or a rep's own templates. Then get the install file from the admin console (Team settings → Install files → Download restack-team.xml), remove the old add-in and install this one, as above.

Don't use the Create team install file button to update. It makes a new team key, which can't open the templates you've already published.

Try a new version first: Restack Beta

Restack Beta is a second copy of the add-in, just for you, that runs whatever is in this repository's beta folder. It sits next to Restack in Outlook, so you can try a new version on real emails before your reps get it.

  1. Once: upload the beta folder (a full copy of Restack) to this repository, so it sits next to these files.
  2. Once: in the admin console, choose Team settings → Install files → Download restack-beta.xml, and install the restack-beta.xml it downloads the same way as Restack's. It shows up as Restack Beta, with a black β on its icon.
  3. Each new version: upload its files into the beta folder first and try them in Restack Beta. When it's ready, upload the same files to the main folder.

Restack Beta uses your published templates and team settings. Its own choices (Appearance, Text size, View, pinned templates) and any template changes you haven't published are kept apart from Restack's. Keep restack-beta.xml to yourself: it carries your team key.

Privacy

The add-in runs inside Outlook. Attachments are read and combined on your computer. If your team admin turns on automatic attaching, PDFs made with Email are uploaded to the admin's own Azure function so Outlook can download them into the new email; those links stop working after an hour and the files are then deleted. If your team admin turns on usage counts, your panel sends counts to the admin's own Azure function each time it saves a PDF or creates an email: your email address, when, how many files, pages and PDFs, the template's name and which accessorials. Never the files, file names, load numbers or customer addresses. Team templates and settings are stored on this site encrypted with your team's key, which only your install file contains. Personal templates are saved in each person's Outlook account.
