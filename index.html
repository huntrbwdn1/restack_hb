Thread Attachments for Outlook

Test build 0.8.1

See every attachment in an email thread in one list, preview them, and combine the ones you pick into a single PDF to email or save.

Set up your team

Do this once. You'll manage the team's email templates, and only people you send the install file to can use the add-in.

  2. In Outlook, remove any older Thread Attachments: open aka.ms/olksideload, choose My add-ins, and under Custom Addins choose … → Remove.
  3. In the same window, choose Add a custom add-in → Add from File, pick thread-attachments-team.xml, and choose Install.
  4. Open Thread Attachments in Outlook, choose Email ▾ → Create a template…, add your team templates, and click Publish to team. Upload the team.json it downloads to this repository (Add file → Upload files → Commit changes).
  5. Send the same thread-attachments-team.xml to your reps.

Keep that file. Clicking the button again makes a new team key, which can't open templates you've already published. You can download it again any time from the add-in: Email ▾ → Manage templates → Share install file. Anyone who has the file can use the add-in and see the team templates, so share it only with your team.

Install (reps)

  1. Save the thread-attachments-team.xml file you were sent.
  2. Open aka.ms/olksideload. Outlook opens the Add-ins for Outlook window after a few seconds.
  3. Choose My add-ins. Under Custom Addins, choose Add a custom add-in → Add from File, pick the file, and choose Install.
  4. New Outlook and Outlook on the web show the button right away. Classic Outlook can take up to a day.

No Add a custom add-in option? Your organization doesn't allow installing custom add-ins. An admin can deploy the same file from the Microsoft 365 admin center (Settings → Integrated apps).

Use

  1. Select the emails. In new Outlook or Outlook on the web, click the conversation and every message in the thread is included. In classic Outlook, expand the conversation and Ctrl+click its messages.
  2. Click Thread Attachments on the ribbon. Every attachment shows up once, oldest first, even if it was sent back and forth, with a small picture of it so you can tell a POD scan from a photo of the truck.
  3. Check the files you want, or Select all. Nothing is checked until you pick. Click a picture or the eye icon to preview a file, and untick any pages you don't want.
  4. For a load with more than one stop, tick Multi-stop. Each file you check gets a stop number (change it if it's wrong, or to put two photos in one stop). If one PDF holds several stops, open its preview and pick a stop for each page. You get one PDF per stop, named 3645493-1, 3645493-2 and so on, whatever their size. A stop's POD that comes in later can go out on its own as -2.
  5. Choose Email ▾ and pick a template (or Blank email). Type the load number, and tick Detention, Lumper or Other to add those details to the message. Create email names the PDF after the load and opens a new email with the recipients and message filled in. The subject is always the load number and POD(s), like 3645493 POD(s). If your team admin has set up automatic attaching, the PDF is already attached; otherwise click Attach PDF on the new email's ribbon. To keep a copy instead, choose Save PDF… and type a name.

PDFs, photos and fax scans (TIFF) go into the combined PDF. Word and Excel files are listed but can't be combined yet. Only the team admin makes templates to start with. To let reps add their own too, the admin ticks Reps can make their own templates under Email ▾ → Manage templates and publishes. A template (and Save PDF) can split PDFs over a size you choose into 3645493-1, 3645493-2 and so on.

Privacy

The add-in runs inside Outlook. Attachments are read and combined on your computer. If your team admin turns on automatic attaching, PDFs made with Email are uploaded to the admin's own Azure function so Outlook can download them into the new email; those links stop working after an hour and the files are then deleted. Team templates and settings are stored on this site encrypted with your team's key, which only your install file contains. Personal templates are saved in each person's Outlook account.
