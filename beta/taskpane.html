          Team

          With your PDF Emails Azure function set up, Create email opens with the PDF already attached, for everyone on your team.

          Files with one of these words in their name start out tagged Receipt, so they go after the PODs (or into their own file) without a click. It works for each rep who turns on Tag receipts by file name in their Settings.

          With your Restack Usage Azure function set up, each rep's panel counts the PDFs it makes and saves and the emails it creates, and the admin console's Usage tab shows everyone's numbers. Only counts are sent: no files, file names, load numbers or customer addresses.

          Publishing

          Publish to team downloads team.json for you to upload to your GitHub repository. With a GitHub token here, it goes straight to GitHub instead.

          Install files

          restack-team.xml is what reps install. restack-beta.xml is Restack Beta, for you: it runs whatever is in your repository's beta folder, next to Restack, so you can try a new version before reps get it. Both carry your team key, so keep them within your team.
